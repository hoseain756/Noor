# NOVA browsing, navigation and personal library

## Audit and changes

The original shell mounted all five tabs immediately, triggering unrelated catalog requests at launch. Tablet navigation hid all destinations behind a menu; the dock had icon-only targets as small as 38 dp and used the same physical tab order in both languages. Search could display an old request after the user changed or cleared the query. Kids trusted a Family genre without requiring an age certificate. Several screens used fixed-height controls and eager collection/agenda lists; live playlist parsing ran synchronously on the UI isolate. Calendar futures accumulated indefinitely.

NOVA mounts each tab on first visit, preserves visited state and disables inactive tickers. The phone's floating glass capsule defaults to Classic (icons with labels), and Settings → Appearance can switch it to Compact icons (same geometry without labels) or Mini (a slimmer capsule inset from both phone edges). All styles retain the shared moving active-tab highlight; Mini uses 48 dp tab targets. Compact and Mini keep each localized tab name in semantics and show it as a tooltip. `navigationBarStyle` is stored in the existing settings bucket and updates the shell immediately. From 840 dp up, the persistent side rail remains unchanged for all three choices; the selector styles the horizontal dock when it is present and does not turn the tablet rail into a bottom bar. Search invalidates stale requests and retains a bounded in-session query cache. Kids withholds uncertified content, obtains missing certificates through bounded detail requests and preserves its locked session across app restarts. Collection and agenda rows build lazily. M3U and XMLTV parsing run through Flutter compute on native platforms. Calendar caching is capped at 12 entries with a 15-minute lifetime.

## Information architecture and flows

Primary navigation: Home → Anime → Kids → My Library → Settings, mirrored by Directionality. The same order is supplied in both locales. Secondary destinations are available in the search browse hub and tablet navigation: Discover, Movies, Series, Add-on catalogs, Live TV, Calendar, Downloads, Viewing statistics and Add-ons.

Library → Watchlist / History / Collections → title detail. Library also exposes Downloads and the existing magnet/torrent flow. Collections support create, edit, delete with confirmation, copy share code, import, add titles and remove with Undo. The detail-page collection picker can create a collection inline instead of dead-ending when no collections exist.

Kids entry requires a configured parent PIN. Exit through another tab, tablet destination or system back verifies the PIN. The device-local active Kids flag is written before navigation; a restored Kids session mounts no unrestricted home page. Global search is hidden in Kids. Kids detail routes receive kidsMode=true, preserving the restriction into recommendations. Root incoming-link handling also checks the persisted Kids session.

## Responsive page specifications

Shared editorial headers use 24 dp logical padding and content-sized typography. Actions wrap below copy below 680 dp of available width; above that they sit alongside. Grids calculate columns and actual image width from layout constraints, with 20 dp gutters and text-scaled row height. Poster ratios remain consistent with the shared PosterCard. Page limits are 1200–1440 dp depending on content.

- Shell: phone dock below 840 dp; persistent 84 dp side rail at 840–1199; expanded 240 dp side navigation at 1200+. The three Appearance dock styles are shared by the live dock and its non-interactive Settings preview; the tablet rail stays the same in every style. Home remains full-bleed. Non-hero destinations own their safe area. Scroll hide is disabled in Kids, on tablets and for accessible navigation. A 40 dp downward movement hides phone chrome, 16 dp upward reveals it.
- Search: 94% modal height with keyboard inset, persistent search field, type filters, a browse hub before typing, lazy poster results after a 350 ms debounce. Clear invalidates in-flight work. Loading presents static skeletons; failure has retry; successful zero results explain how to broaden a search.
- Anime: editorial lead title with adaptive artwork/copy composition, For You / Series / Films filters, personal AniList watching/planning rails, prominent provider search and preserved tracker linking. Anime search uses the same responsive modal grid and switches between AniList and MyAnimeList. Tracker sheet separates identity, status, episode progress and score; its footer remains available while content scrolls. Failed progress preload blocks editing and offers retry, preventing accidental overwrite of unknown remote progress. Tracker removal requires confirmation.
- Discover / Movies / Series / Catalogs: one scrolling canvas with headline, search, wrapping type/sort controls and an adaptive lazy grid. Sort/filter operations run locally against already-loaded rows. Refresh preserves visible content; initial load uses skeletons. Single-catalog pages preserve preloaded content while refreshing their loader.
- Kids: a brighter primary-container opening with oversized typography, movie/series exploration chips and spacious poster choices. The saved kidsCardSize preference controls preferred 140 / 170 / 220 dp card widths. Explicit certificate allowlist: G, PG, TV-Y, TV-Y7, TV-G, TV-PG, U, 0, 6, 7, case-insensitive. Family/Animation genres never suffice. Unrated, unknown, 12+, PG-13, R and TV-MA content is withheld. Empty states explain this rule without weakening it.
- Library: personal editorial heading, Downloads / Open torrent actions, wrapping counted view chips and title search. History uses larger thumbnails, localized dates, direction-correct disclosure and progress. Watchlist removals are reversible with Undo. Collections use a lazy cover-stack list with descriptions; collection detail exposes clear sharing/edit actions above a responsive grid.
- Calendar: editorial weekly agenda, mirrored previous/next controls, locale-native dates, wrapping day selection and Today reset. Date group headings and episode cards are lazy. Episode tiles adapt their artwork and copy to available width; release dates are converted to local time.
- Live TV: an editorial channel hub with playlist management, search, wrapping group filters and one-column phone / two-column tablet channel cards. Each card shows source identity, live programme when present, programme progress and a clear play affordance. Playlist removal is confirmed. Add-playlist dialog groups name, M3U and optional XMLTV URLs; URL inputs remain LTR in Arabic.

## Components, states and motion

NovaBrowseHeader, NovaBrowseFeature, NovaBrowseDestination and NovaBrowseSkeleton live in features/shell/nova_browse_widgets.dart. They consume theme colorScheme values so the shared NOVA light/dark system determines all surfaces and text. Shared inputs/buttons/chips/dialogs inherit NOVA component themes. Static skeletons avoid a perpetual full-page shimmer. Loading, successful content, empty and retry states exist for network-driven pages; in-memory library pages show actionable empty states. Destructive playlist and collection deletion requires confirmation; quick title removals provide Undo.

The existing capsule sliding indicator and scrub gesture remain intact: 350 ms cubic ease for tab movement, 150 ms press feedback, 200 ms initial appearance. reduceMotion disables dock motion as well as the platform reduced-motion flag. Dock glass uses a single static fill, with reduceTransparency making it opaque; there is no expensive stacked blur. Shell chrome opacity uses 220 ms ease. Universal play/check/brand icons never mirror; navigation chevrons and layout order follow direction. Buttons have at least 48 dp interaction targets; compact landscape dock targets stay at least 44 dp high. Dock semantics exposes a single full label without duplicating the visible tab text.

## Verification and limitations

Automated NOVA browse tests cover certificate safety (including unrated Family genre rejection), logical and physical nav mirroring, target sizing, 200% library text on 320/900 dp surfaces in both directions and brightness modes, and clearing a search while an older request is pending. Full real-device 60 fps profiling and a live service-account exercise require a device and actual connected accounts; static analysis and widget tests do not prove those outcomes.

Catalogs that never deliver an age certificate may yield an empty Kids experience; this is the intentional safe behavior. Certificate metadata comes from the installed catalog provider, not an independent content certification authority. Search's bounded query cache is session-local; repository/API caching is handled by the shared data layer. Flutter compute runs off the UI isolate on native targets, while web implementations use the event loop. Live programme progress is refreshed when the page rebuilds; it is not a continuously ticking TV guide. The calendar retains the existing 60 tracked-series fetch cap and AniList scheduling window.
